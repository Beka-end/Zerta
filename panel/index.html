Что делать после оплаты

  1. Проверьте бизнес. Есть ИИН или БИН — найдите на kgd.gov.kz в поиске налогоплательщика. Сошлось — значок «Проверено». Нет номера — позвоните и поставьте «Контакт».
  2. Удалите ИИН из переписки. Сразу после проверки. У вас остаётся только факт и дата.
  3. Заполните форму слева и нажмите «Собрать карточку» — скачается файл вида nan-kofe.html.
  4. Положите файл в папку biz/ вашего проекта.
  5. Вставьте строку каталога в файл data.js — сразу после строки const BUSINESSES=[. Больше ничего в проекте трогать не нужно.
  6. Вставьте строку в sitemap.xml перед закрывающим тегом.
  7. Отправьте изменения:
    git add .
    git commit -m "Добавил Нан & Kofe"
    git push
  8. Дата окончания уже в строке. После неё карточка скроется из каталога сама — вручную ничего удалять не нужно. Напомните клиенту за три дня.
Снять карточку раньше срока: поменяйте в её строке status:"active" на status:"off" и отправьте изменения. Файл в папке biz/ оставьте — если клиент вернётся и оплатит, достаточно вернуть строку обратно.
