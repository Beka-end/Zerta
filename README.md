# KÁSIP.kz — каталог бизнесов Казахстана

Статический сайт. Никакой сборки, серверов и баз данных: HTML, CSS и немного JavaScript. Открывается локально двойным кликом, деплоится на Vercel за две минуты.

Владелец: ИП «Б.А.С.Т.А. PAY GROUP»

---

## Деплой: от папки до работающего сайта

**1. Создайте репозиторий на GitHub.** Зайдите на github.com, нажмите «New repository», назовите `kasip`, выберите Private и создайте. Ничего не добавляйте — ни README, ни .gitignore, они уже здесь.

**2. Загрузите папку.** В терминале, находясь внутри папки `kasip`:

```bash
git init
git add .
git commit -m "Первая версия каталога"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/kasip.git
git push -u origin main
```

Если терминала под рукой нет — на странице пустого репозитория есть кнопка «uploading an existing file», можно просто перетащить туда все файлы мышью.

**3. Подключите Vercel.** Зайдите на vercel.com через свой GitHub, нажмите «Add New → Project», выберите репозиторий `kasip` и нажмите «Deploy». Никаких настроек менять не нужно: Vercel сам поймёт, что это статические файлы.

Через минуту сайт будет по адресу вида `kasip.vercel.app`.

**4. Дальше каждое обновление — три команды:**

```bash
git add .
git commit -m "Добавил карточку такого-то бизнеса"
git push
```

Vercel пересоберёт сайт сам за несколько секунд.

## Что заменить перед запуском

**Домен.** Сейчас везде прописан `https://kasip.vercel.app`. Когда купите домен `.kz`, замените его в `robots.txt`, `sitemap.xml`, в теге canonical на главной, в панели (переменная `SITE` в скрипте) и в каждой уже созданной карточке в папке `biz/`.

Домен в зоне `.kz` регистрируется у казахстанских регистраторов и требует подтверждения регистрации бизнеса. Для доверия клиентов это важнее, чем кажется: `kasip.vercel.app` в глазах предпринимателя выглядит как «мальчик что-то сделал», а `kasip.kz` — как компания.

**Номер WhatsApp.** Заявки уходят на +7 708 271 59 54. Чтобы сменить — правьте строку `const OWNER_WA` в `index.html` и в `panel/index.html`: номер разбит на четыре куска, чтобы его не выцепили спам-боты.

## Как добавить новый бизнес

**Самый быстрый способ — панель.** Двойной клик по `panel/index.html`, код **2404**.

Панель намеренно не публикуется: папка `panel/` добавлена в `.gitignore`, поэтому на сайт она не попадает и по адресу `/panel` ничего не откроется. Это не ограничение, а осознанный выбор — публиковать карточки всё равно можно только с компьютера, где стоит git, а значит и панель нужна только там. Файл остаётся у вас локально и работает без интернета.

Экран с кодом оставлен на случай, если файл окажется на чужом компьютере или вы всё же решите его выложить. Код хранится хешем, попыток пять. Помните: на статическом сайте такая проверка происходит в браузере, а не на сервере, и специалист её обойдёт. Настоящая защита появится только вместе с серверной частью.

Поменять код: посчитайте SHA-256 нового значения на любом онлайн-калькуляторе хешей и замените строку `const HASH=` в начале скрипта `panel/index.html`.

Если позже понадобится доступ с телефона — не выкладывайте панель как есть. Правильный путь: поставить домен под Cloudflare и закрыть адрес через бесплатный Cloudflare Access, либо дождаться перехода на базу данных с серверным входом.

Перенесите в панель данные из заявки, перенесите данные из заявки в WhatsApp и нажмите «Собрать карточку». Панель скачает готовый файл страницы и покажет две строки: одну для каталога, вторую для карты сайта. Останется положить файл в `biz/`, вставить строки и сделать `git push`. Панель ничего никуда не отправляет и закрыта от поисковиков.

Ниже — то же самое вручную, если захотите поправить что-то тонко.

**1. Скопируйте любую готовую карточку из `biz/`** в `biz/название-бизнеса.html`. Имя файла — латиницей, без пробелов, через дефис: `nan-kofe.html`, `astana-auto.html`. Это будет адрес страницы, его увидят в Google.

**2. Замените в новом файле:** заголовок и описание в `<title>` и `<meta name="description">`, ссылку canonical, название в `<h1>`, значки, тексты разделов, цены, контакты в правой колонке и блок `application/ld+json` внизу — он объясняет поисковику, что это компания, а не просто страница.

**3. Если бизнес офлайновый** — раскомментируйте блок «Как добраться» в середине файла и вставьте адрес и ссылки на 2GIS и Google Maps. Комментарий начинается с `<!--` и заканчивается `-->`, уберите эти две строки.

**4. Добавьте карточку в каталог.** Откройте `data.js` и добавьте объект сразу после `const BUSINESSES=[`:

```js
{n:"Нан & Kofe", c:"food", city:"Шымкент", mode:"both",
 d:"Пекарня полного цикла. Доставка выпечки в офисы с 7:00.",
 v:1, p:"от 900 ₸", url:"biz/nan-kofe.html",
 geo:"https://2gis.kz/shymkent/firm/..."}
```

Если в `data.js` будет ошибка — пропущена запятая или кавычка, — сломается только каталог, а не весь сайт: страница откроется и покажет подсказку, что проверить. Форма размещения, тарифы и страницы карточек продолжат работать.

Значения полей: `c` — категория, совпадает с `data-cat` у кнопок фильтра; `mode` — `online`, `offline` или `both`; `v` — значок: `1` проверен по реестру, `2` подтверждён телефон, `0` без значка; `geo` — ссылка на карту, для онлайн-бизнеса пустая.

**5. Добавьте страницу в `sitemap.xml`** — скопируйте блок `<url>` и поменяйте адрес. Без этого Google найдёт страницу позже.

## Добавить карточку без терминала

Всё можно сделать мышью на github.com, командная строка не нужна.

1. Откройте свой репозиторий, зайдите в папку `biz`, нажмите **Add file → Upload files** и перетащите файл, который собрала панель. Внизу нажмите **Commit changes**.
2. Вернитесь в корень, откройте `data.js`, нажмите значок карандаша, вставьте строку из панели сразу после `const BUSINESSES=[` и снова **Commit changes**.
3. Так же откройте `sitemap.xml` и вставьте блок `<url>` перед закрывающим тегом.
4. Vercel пересоберёт сайт сам за полминуты. Обновите страницу каталога и проверьте, что карточка появилась.

**Если каталог опустел** — значит в `data.js` пропущена запятая или кавычка. Не паникуйте и ничего не переделывайте: на github.com откройте вкладку **Commits**, найдите последнее изменение, нажмите **Revert** — сайт вернётся к рабочему состоянию за минуту. Потом повторите вставку внимательнее.

## Тарифы и оплата

Два варианта, набор возможностей одинаковый — разница только в сроке:

- **помесячно** — 4 990 ₸ за 30 дней
- **на год** — 49 900 ₸, два месяца в подарок

Ссылка Kaspi одна на оба варианта: **pay.kaspi.kz/pay/cwevqlzj**. Сумму клиент вводит на странице Kaspi сам, поэтому смотрите не на договорённость, а на чек — сколько пришло, на столько и включайте. Записывайте сумму рядом с датой, иначе через полгода не вспомните, кто платил за год.

Автосписаний нет: продление происходит только по новой оплате клиента. Напоминайте за три дня до конца.

## Порядок работы с клиентом

1. Заявка приходит в WhatsApp одним сообщением со всеми полями.
2. Если прислали ИИН или БИН — проверяете на **kgd.gov.kz** в поиске налогоплательщика. Сошлось — значок `v:1`. Не прислали — звоните по номеру и ставите `v:2`.
3. **Удаляете ИИН из переписки сразу после проверки.** В учёте остаётся только «проверен» и дата. Это обещано в политике конфиденциальности, и это же защищает вас.
4. Клиент платит по ссылке Kaspi и присылает чек.
5. Создаёте страницу, добавляете в каталог, пушите в git.
6. В таблице учёта записываете дату оплаты и дату окончания: плюс 30 дней.
7. За три дня до конца пишете напоминание. Нет оплаты — убираете карточку из `DATA`, файл страницы оставляете 60 дней.

## Роли

- **Гость** — смотрит каталог и пишет бизнесу в WhatsApp. Ничего не меняет, не регистрируется.
- **Владелец бизнеса** — платит, присылает данные и правки, может потребовать удаления. Прямого доступа к сайту нет: все изменения идут через вас.
- **Администратор (вы)** — проверяет ИИН, принимает оплату, публикует и снимает карточки, ставит значки. Единственный, кто отправляет изменения на GitHub.
- **Помощник (если появится)** — готовит карточки в панели и публикует. Не касается денег, не ставит значок «Проверено», не удаляет чужие карточки.

Правило: для каждой новой роли пишите три строки — что видит, что меняет, чего не может никогда. Третья строка важнее первых двух.

## Что нельзя делать никогда

**Не наполняйте каталог выгрузками из Instagram, 2GIS и справочников.** С 25 августа 2026 года закон прямо говорит: если человек сам разместил свои данные в открытом доступе, это не значит, что он согласен на их сбор. Карточка появляется только по заявке владельца. Штрафы по этой статье измеряются миллионами тенге и способны закрыть проект.

**Не публикуйте чужие ИИН.** Ни в карточке, ни в описании, нигде.

**Не ставьте значок «Проверено» без реальной проверки.** Значок — это единственное, что отличает вас от бесплатной доски объявлений.

## Юридический статус

Уведомление уполномоченному органу о начале обработки персональных данных (статья 10-1 Закона РК «О персональных данных и их защите» в редакции Закона № 326-VIII от 24 июня 2026 года) подаётся только крупными операторами — от 500 000 уникальных субъектов. Категории: малые до 10 000, средние от 10 000 до 500 000, крупные от 500 000. Вы — малый оператор, уведомление не подаётся. Это зафиксировано в политике конфиденциальности.

Документы `privacy.html` и `terms.html` написаны под ваш реальный процесс, но не заменяют юридическую консультацию. Перед публикацией покажите их юристу.
